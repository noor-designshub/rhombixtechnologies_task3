# 📚 NOOR. — Personal Book Library

A modern and responsive **Personal Book Library Management Website** designed to help users organize, manage, search, and track their personal book collection.

The project features a clean dashboard interface with book statistics, category filtering, search functionality, borrowing logs, and an interactive form for adding new books.

---

## ✨ Features

* 📊 Interactive library dashboard
* 📚 Total books statistics
* ✅ Available books tracking
* 🤝 Borrowed books tracking
* 📂 Dynamic category statistics
* 🔍 Search books by title or author
* 🏷️ Filter books by category
* 📌 Filter books by availability status
* ➕ Add new books
* 🖼️ Optional book cover image URL
* 👤 Author information
* 📋 Dynamic book collection
* 📑 Borrowing history table
* 📅 Borrow and return date tracking
* 📱 Responsive mobile layout
* 📲 Mobile sidebar navigation
* 🎨 Modern dashboard-style UI
* 🪟 Interactive add-book modal
* 🔤 Modern Plus Jakarta Sans typography
* ⭐ Font Awesome icons

## 🖥️ Website Sections

### 📊 Dashboard

The dashboard provides an overview of the library through four statistic cards:

* **Total Books**
* **Available**
* **Borrowed**
* **Categories**

These sections give users a quick overview of their library.

---

### 📚 Books Collection

The **Books Collection** section allows users to manage and track their reading inventory.

It includes a search bar and filtering controls to make finding books easier.

Users can search by:

* Book title
* Author

---

### 🔎 Search Functionality

The search field allows users to find specific books by entering a title or author's name.

```text
Search titles or authors...
```

---

### 🏷️ Category Filtering

Books can be filtered using the category dropdown.

Available categories include:

* Business
* Self Development
* Technology
* Fiction

The Add New Book form also supports:

* Education
* Other

---

### 📌 Status Filtering

Users can filter books according to their current status:

* Available
* Borrowed

This makes it easier to identify which books are currently in the library and which have been borrowed.

---

### ➕ Add New Book

The **Add New Book** button opens an interactive modal form.

Users can provide:

* Book Title
* Author
* Cover Image URL
* Category

Example:

```text
Book Title: Clean Code
Author: Robert C. Martin
Category: Technology
```

The form includes validation for required fields before a book can be saved.

---

### 📂 Categories

The Categories section provides a dynamic overview of the genres represented in the library.

It is designed to help users quickly understand how their book collection is distributed across different categories.

---

### 📑 Borrowing History

The **Borrowing Logs** section displays borrowing information in a structured table.

The table contains:

| Field       | Description                     |
| ----------- | ------------------------------- |
| Book        | Name of the book                |
| Borrower    | Person who borrowed the book    |
| Borrow Date | Date the book was borrowed      |
| Return Date | Date associated with the return |
| Status      | Current borrowing status        |
